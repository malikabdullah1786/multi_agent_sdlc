# Enterprise AI Software Engineering Team (Multi-Agent SDLC Platform)

An autonomous AI software engineering platform where multiple specialized AI agents collaborate to design, develop, test, review, and deploy software applications.

## Services

- **/backend**: FastAPI app managing REST and WebSocket connections, database models, background queues.
- **/agents**: LangGraph & LangChain multi-agent orchestration engine.
- **/frontend**: Next.js App Router UI for tracking workflows, viewing agent logs, and processing approvals.
- **/shared**: Shared utilities and schemas.
- **/infra**: Deployment configs (Docker, K8s, Terraform).
